# ForecastHub – Community Prediction Platform

**Team:** Xinlai Chen, Qiong Wu

## Description

ForecastHub is a prediction platform for small groups such as student clubs, classes, campus organizations, and groups of friends. People in these groups often debate upcoming events. Some are campus events, such as how many students will attend the industry panel next Monday. Many are real-world events, such as which team will win the World Series, or how a weekend football game will turn out. People also guess about everyday things, like whether it will rain this weekend or whether gas prices will rise next month. These conversations usually happen casually and are quickly forgotten.

ForecastHub turns these debates into friendly competitions. Each group has its own space where organizers post YES/NO questions, such as "Will the average gas price in California be above $6.00 on December 1?" Members submit a prediction with a confidence level (for example, "70% YES") before the deadline. The group's overall prediction updates automatically, and a chart shows how opinions change over time. When the event ends, the organizer confirms the outcome using the question's stated criteria and source, and the system awards virtual points based on how accurate each prediction was. Members who are both correct and confident earn the most points, and everyone can compare results on a leaderboard. ForecastHub does not involve real money or betting of any kind.

## User Stories

1. As a member, I want to join a group using an invitation link or code, so that I can take part in prediction competitions with my classmates, friends, or club members.
2. As a member, I want to browse prediction questions by category, such as campus events, sports, weather, and prices, so that I can quickly find the topics I care about.
3. As a member, I want to submit a YES/NO prediction with a confidence level before the deadline, and change it if I change my mind, so that I can share my view and compete with others.
4. As a member, I want to see the group's current prediction and a chart of how it has changed over time, so that I can compare my view with others and see how opinions shift.
5. As a member, I want to earn virtual points for accurate predictions and view a leaderboard, so that I can track my performance and enjoy friendly competition.
6. As an organizer, I want to create prediction questions with a deadline, clear outcome criteria, and a trusted source for the result, then confirm the final outcome, so that competitions in my group are fair and easy to resolve.
7. As an administrator, I want to create a group, manage members, assign organizer permissions, and moderate prediction questions, so that the group stays organized and the platform is used appropriately.
